# Supreme Enterprises Website

This is a ready-to-open website for a local print shop business.

## How to Open

1. Open this folder:
   `C:\Users\User\Documents\Codex\2026-05-05\build-a-modern-web-app-with\supreme-enterprises-print-shop`
2. Double-click `index.html`.
3. The website will open in your browser.

## Files

- `index.html` - page content and sections
- `style.css` - layout, colours, responsive design, and animations
- `script.js` - mobile menu and contact form validation
- `assets/` - local website visuals and service icons
